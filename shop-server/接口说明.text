✅ 功能说明

/products → 获取全部作品（可分页）

/product/:id → 获取单个作品详情

/product/create → 创建作品

/product/upload → 上传媒体

/uploads → 静态访问媒体文件

/ → 静态访问前端 MediaUploader.html
